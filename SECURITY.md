# Security Policy

## Supported Versions

Security fixes are provided for the latest published version of Mitori.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting form under the repository's **Security** tab. Include the affected Mitori version, macOS version, reproduction steps, impact, and any relevant logs.

Remove passwords, two-factor authentication codes, cookies, Apple ID identifiers, device identifiers, and other account data before attaching screenshots or logs.
